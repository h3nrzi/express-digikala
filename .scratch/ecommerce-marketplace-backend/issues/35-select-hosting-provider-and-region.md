# انتخاب ارائه‌دهنده و منطقهٔ میزبانی نسخه اول

## Question

با تکیه بر [ارزیابی گزینه‌های ارائه‌دهنده و منطقهٔ میزبانی نسخه اول](33-research-hosting-provider-options.md) و نتیجهٔ [تأیید عملی بازیابی و دسترس‌پذیری گزینه‌های میزبانی](34-verify-hosting-recovery-and-serviceability.md)، کدام ارائه‌دهنده و منطقه برای اجرای production انتخاب شوند؟ تصمیم باید اجرای API و worker، PostgreSQL و object storage، محل پشتیبان، دسترس‌پذیری واقعی از شبکه‌های پایلوت، بار عملیات، هزینه، محدودیت‌های قانونی داده، و تعهد/شواهد RPO حداکثر ۴ ساعت و RTO حداکثر ۸ ساعت را یکجا بسنجد. اگر هیچ گزینه‌ای این معیارها را برآورده نکند، آیا گزینهٔ تازه‌ای باید ارزیابی شود یا هدف کیفی با یک تصمیم صریح بازنگری شود؟

## Answer

به تصمیم کاربر دربارهٔ محدودهٔ مقصد، انتخاب ارائه‌دهنده و منطقهٔ production از این نقشه خارج شد. این انتخاب پس از تکمیل شواهد پیش‌پایلوت و پیش از production انجام می‌شود؛ در این نقشه هیچ میزبانی به‌عنوان گزینهٔ تأییدشده انتخاب نشده است.
